# Hora de Aprender! 🦉

App em português de Portugal para aprender as horas (relógio analógico) e o calendário.

- **Relógio**: "Que horas são?" (lê os ponteiros e escreve a hora) e "Põe as horas!" (arrasta os ponteiros). 5 níveis.
- **Calendário**: ano inteiro, perguntas como "Clica na 2.ª terça-feira de fevereiro". 4 níveis.

## Usar
Abrir `index.html` no browser (ou `python3 -m http.server`). Funciona também no GitHub Pages.
O nível e as estrelas ficam guardados no browser.
